# BMI Calculator (เครื่องคำนวณดัชนีมวลกาย)

เว็บแอปพลิเคชันขนาดเล็ก (Vanilla JavaScript) สำหรับคำนวณค่าดัชนีมวลกาย (BMI) เพื่อเช็คเกณฑ์สุขภาพเบื้องต้น รองรับการแสดงผลแบบ Responsive คลีน มินิมอล


## Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Styles)
* **Logic:** Vanilla JavaScript (ES6+)
* **🎨 UI Elements & Emojis:** พัฒนาและตกแต่งหน้าเว็บด้วย Emoji และสัญลักษณ์ต่างๆ โดยเรียกใช้ผ่านระบบ Clipboard History ของ Windows (คีย์ลัด `Windows` + `V`)
